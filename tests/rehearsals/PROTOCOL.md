# Workflow rehearsals

Run each input through the named skill in a native agent session with only its supplied context.
Use an isolated output directory, no external mutations and no additional model-provider API.
Record the actual artifacts and observations in the test work record/PR, not this reference.

Review behavior, not wording: relevant interview/stakes; explicit scope stays local; unresolved
contradictions hold affected work; clear bugs return to repair; missing evidence is not a pass;
resumed work uses agreed criteria; no invented schedule/write/quiz result; explanation is useful
and answer keys are not served. Preserve useful unaffected work/evidence and one canonical spec.

These fixtures test instruction behavior. They do not prove product correctness, deployed
integration, registered recurrence or guaranteed enforcement in every harness.
